# СкинСтудия для Android

Официальные тестовые APK. Новости и обсуждение: [@SkinStudioN](https://t.me/SkinStudioN).

## Скачать обновление 0.20.1

[**Скачать APK 0.20.1**](https://github.com/Momoral67/skinstudio-releases/releases/download/v0.20.1/SkinStudio-0.20.1.apk) · [Описание выпуска и проверка файла](https://github.com/Momoral67/skinstudio-releases/releases/tag/v0.20.1)

Android 8+ с обновлённым Android System WebView / Chrome. Устанавливай поверх прежней версии, не удаляя приложение. Важные проекты заранее сохрани экспортом `.skinstudio`.

Обновление усиливает проверку картинок проектов и штампов, ограничивает память и доступ Android к файлам, добавляет строгую политику исполнения скриптов. Исправлены две уязвимости инструментов сборки.

395 тестов прошли. На Android API 35 все 282 исходных проекта в ходе обновления сохранили полные SHA-256. В выпуске приложены контрольная сумма APK, инструкция, публичный сертификат и подробные ограничения.

Это тестовая версия. Полная безопасность не подтверждена независимым аудитом; физические телефоны и антивирусное сканирование пока не проверены. Подготовка объёмных вещей к публикации требует проверки в Roblox Studio. СкинСтудия разработана независимо от Roblox.
